## Introduction

HomeLoan is an application designed to streamline the process of applying for and managing home loans. It provides a secure platform for users to apply for loans, track their application status, and view available loan offerings.

## Features

- Secure user authentication with JWT
- EMI calculation
- Loan tracking
- Admin management
- Integrated with Swagger for API documentation and testing

## Technologies Used

- **Backend:**
  - Spring Boot
  - JWT
  - Hibernate
  - MySQL

- **Frontend:**
  - HTML
